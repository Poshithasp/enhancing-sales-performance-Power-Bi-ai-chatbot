# Enhancing Sales Performance Through Power BI Visualization and AI Chatbot

## Project Overview
This project combines Power BI dashboards and an AI-powered chatbot to analyze sales performance and support business decision-making.

## Features
- Interactive Power BI Dashboard
- Revenue Analysis
- Profit Margin Analysis
- Customer Insights
- Market Performance Analysis
- AI-powered Chatbot
- Conversational Analytics

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Python
- AI Chatbot

## Key Results
- Revenue Analysis of ₹142M+
- Sales Quantity Analysis of 350K+
- Identification of top-performing customers and markets
